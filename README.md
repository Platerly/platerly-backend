# Platerly Backend (API)

This is the official backend API for [Platerly](https://www.platerly.com) — a recipe social network with halal and allergy-aware design.

### 🛠️ Tech Stack
- ASP.NET Core 8
- C#
- Azure Blob Storage
- Entity Framework Core
- SendGrid Email Integration
